What it does

Everything you need to mine smarter

Built for the SC mining and salvage workflow — no fluff, no subscriptions.

📸

Auto Screenshot Monitoring

Watches your SC screenshot folder. Every new screenshot is scanned automatically — no hotkeys or manual steps.

🧠

Deep Learning OCR

EasyOCR with morphological noise filtering extracts the signature value from your HUD accurately across all HUD scales.

🪨

Ship Mining

Identifies the dominant mineral tier — Legendary, Epic, Rare, Uncommon, or Common — directly from the signature value.

⛏️

Ground Deposits

Distinguishes FPS hand-mining rocks (3000) from ROC and vehicle-class deposits (4000) with 100% single-mineral purity.

🔧

Salvage & Wreck Debris

Hull panels, and sized wreck debris from Avenger-class right up to 890 Jump capital wrecks.

🖥️

In-Game Overlay

Always-on-top popup with the match result. Drag to reposition. Configurable display duration.

📐

One-Time Calibration

Draw a box over the signature HUD element once in Settings. Scanner uses that region on every screenshot thereafter.

🔄

Auto-Update Check

Checks GitHub for new releases on startup and offers a direct download link when one is available.

Setup in minutes

Four steps to go live

Configure once, then just press PrintScreen in-game.

1

Configure scan region

Take one screenshot with a signature visible. In Settings, draw a box over the signature area. Saved permanently.

2

Point to your screenshot folder

Set the path to your Star Citizen screenshot folder and click Start Monitoring.

3

Press PrintScreen in-game

When a signature appears on your targeting HUD, take a screenshot. The scanner detects it automatically.

4

Read the overlay

An always-on-top popup appears with the identification — mineral, tier, and recommended mining method.

Known limitations

What to watch out for

Signature 4000 collision Large ground deposits share 4000 with Common-tier ship-mining rocks. Use context — planet surface vs. space — to distinguish.
Signature 3000 collision FPS small ground deposits and 890 Jump capital wreck debris both read 3000. The overlay shows both candidates; context resolves it.
Undetectable resources Vlk Pearls, Vlk Irradiated Pearls, and Flowstone have signature 0 — the scanner cannot identify these.
Display mode Star Citizen must be in Windowed or Borderless Windowed mode for the overlay to appear over the game window.
First-run model download EasyOCR downloads ~115 MB of model files on first launch. Subsequent startups use the local cache and are fast.
Developers

Run from source

git clone https://github.com/Diftic/SC_Signature_Scanner.git
cd SC_Signature_Scanner
pip install -r requirements.txt
python main.py
1

Python 3.10+ required. Windows 10 or 11 only.

2

Install PyTorch CPU build before running pip install. See the comments in requirements.txt.

3

EasyOCR model files (~115 MB) download automatically on first run into ~/.EasyOCR/model/.

4

Run python build.py to produce a standalone .exe using PyInstaller.
